Theme file downloaded

The file is called theme.css and is in your Downloads folder. Your changes are only on this computer until the file is uploaded. To put it live:

  1. Open the upload page for the site's css folder (you need to be signed in to GitHub with access to the site).
  2. Drag theme.css onto the page. If your browser renamed it (for example theme (1).css), rename it back to theme.css first.
  3. Click Commit changes.
  4. Wait 1–2 minutes, then refresh the site with Ctrl + F5 (Mac: Cmd + Shift + R).

Or send the file to whoever manages the site and they can upload it.
